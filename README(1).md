# Curated Learning Resources

This is a **shortlist**, not a checklist. Choose one primary course or text for each stage, work through its exercises, and use other links as references. Access terms, versions, and course pages can change; confirm current requirements and licenses on the source site.

## Suggested route through the resources

- **New to Python:** CS50 Python or the official Python tutorial; add Git basics.
- **New to data and math:** pandas/NumPy docs, Khan Academy or StatQuest, and small data exercises.
- **New to ML:** Google ML Crash Course, scikit-learn User Guide, and *Introduction to Statistical Learning*.
- **New to deep learning:** pick **one** of Dive into Deep Learning or fast.ai, then use the official PyTorch tutorials.
- **Choosing a specialty:** follow one course in the relevant section below, then build a project and read one paper.

## Programming and data

- [Python Tutorial](https://docs.python.org/3/tutorial/) — language fundamentals and reference.
- [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/) — structured introductory course.
- [Git documentation](https://git-scm.com/doc) — version control.
- [NumPy Learn](https://numpy.org/learn/) and [pandas getting started](https://pandas.pydata.org/docs/getting_started/index.html) — core data tools.
- [SQLBolt](https://sqlbolt.com/) — interactive SQL lessons.

## Math, statistics, and classical ML

- [Khan Academy: Statistics and Probability](https://www.khanacademy.org/math/statistics-probability) — practice and fundamentals.
- [3Blue1Brown: Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra) — visual intuition.
- [StatQuest](https://statquest.org/) — approachable explanations of statistics and ML methods.
- [Introduction to Statistical Learning](https://www.statlearning.com/) — practical textbook with online materials.
- [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) — guided ML concepts and exercises.
- [scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html) — practical estimators, pipelines, evaluation, and model selection.
- [Stanford CS229](https://cs229.stanford.edu/) — more mathematical machine-learning course materials; prerequisites are stronger.

## Deep learning

- [PyTorch Tutorials](https://pytorch.org/tutorials/) — framework tutorials and installation instructions.
- [Dive into Deep Learning](https://d2l.ai/) — interactive textbook with code.
- [Practical Deep Learning for Coders](https://course.fast.ai/) — project-driven learning.
- [Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) — implementation-oriented lectures.
- [Deep Learning (Goodfellow, Bengio, Courville)](https://www.deeplearningbook.org/) — broader reference text; not necessary to read cover to cover at the beginning.

## Specialties and generative AI

- **NLP / transformers:** [Hugging Face Learn](https://huggingface.co/learn), [Stanford CS224N](https://web.stanford.edu/class/cs224n/).
- **Computer vision:** [Stanford CS231n](https://cs231n.stanford.edu/) — course lectures and materials.
- **Reinforcement learning:** [Sutton and Barto's book site](http://incompleteideas.net/book/the-book-2nd.html), [Gymnasium documentation](https://gymnasium.farama.org/).
- **Generative AI systems:** [Full Stack Deep Learning](https://fullstackdeeplearning.com/) — practical system building and evaluation.
- **LLMs in practice:** use framework and model-provider documentation for current interfaces, then verify capabilities and terms with model cards or system documentation. APIs and policies change quickly.

## MLOps, safety, and human-centered practice

- [Made With ML](https://madewithml.com/) — data, modeling, testing, and deployment topics.
- [MLflow documentation](https://mlflow.org/docs/latest/) — experiment tracking and lifecycle tooling.
- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework) — risk management guidance.
- [People + AI Guidebook](https://pair.withgoogle.com/guidebook/) — human-centered AI product design.

## Datasets and papers

- [UCI Machine Learning Repository](https://archive.ics.uci.edu/) — dataset catalog.
- [OpenML](https://www.openml.org/) — datasets and experiments.
- [Hugging Face Datasets](https://huggingface.co/datasets) — datasets and dataset cards.
- [arXiv](https://arxiv.org/) and [OpenReview](https://openreview.net/) — papers and reviews; a preprint is not necessarily peer reviewed.
- [Papers with Code](https://paperswithcode.com/) — tasks, papers, and linked implementations; confirm details in original sources.

## How to evaluate a resource

Before following a course, check its prerequisites, date, version, accessibility, cost, hardware needs, and whether examples are still supported. For datasets, models, and code, check license, consent/permissions, intended use, privacy, and known limitations. Do not treat a leaderboard or course certificate as proof of competence; use projects and clear explanations as evidence.
