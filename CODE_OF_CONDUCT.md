# Code of Conduct

We want this project to be a respectful, useful learning space for people with different levels of experience and backgrounds.

## Our standards

Examples of behavior that help build a welcoming community include:

- being considerate and constructive;
- explaining technical disagreements with evidence and curiosity;
- welcoming beginner questions and correcting mistakes kindly;
- acknowledging others' work and using inclusive language.

Unacceptable behavior includes harassment, insults, discrimination, intimidation, deliberate disruption, or sharing someone's private information without permission.

## Reporting

If you experience or witness behavior that violates these standards, contact the project maintainer through the repository's GitHub contact or private reporting option. Share only the information needed to understand the concern. Maintainers should review reports promptly, protect the reporter's privacy where possible, and take fair action appropriate to the situation.

This code applies in project spaces and when someone is representing the project in public. Maintainers are responsible for applying it consistently.
