# Glossary

Plain-language definitions. Many terms have more precise meanings in particular subfields; use the linked curriculum modules for context.

- **AI (artificial intelligence):** A broad field concerned with systems that perform tasks associated with intelligent behavior.
- **Algorithm:** A procedure or set of steps for solving a problem.
- **Baseline:** A simple reference method used to judge whether a more complex method adds value.
- **Batch:** A group of examples processed together, often during one optimizer update.
- **Bias (statistical):** Systematic error in an estimate or model. This is distinct from social bias, though they can interact.
- **Classification:** Predicting a category or class.
- **Data leakage:** Information unavailable at real prediction time, or information from evaluation data, improperly influencing model training or selection.
- **Deep learning:** Machine learning using neural networks with multiple layers.
- **Embedding:** A vector representation of an item, such as a word, sentence, image, or user.
- **Epoch:** One pass through the training examples, usually divided into batches.
- **Feature:** An input variable or representation given to a model.
- **Fine-tuning:** Further training a pretrained model on a task- or domain-specific dataset.
- **Generalization:** How well a learned method performs on relevant unseen examples.
- **Gradient:** A vector of derivatives describing how a function changes with its inputs or parameters.
- **Hyperparameter:** A setting selected outside the ordinary parameter-learning process, such as a learning rate or tree depth.
- **Inference:** Using a trained model to produce outputs for new inputs.
- **Label / target:** The outcome or category a supervised model is trained to predict.
- **Loss:** A numerical measure used to train or compare model predictions against targets.
- **Machine learning:** Methods that use data to learn patterns for prediction, generation, ranking, or related tasks.
- **Metric:** A defined measurement used to summarize a model's behavior for a particular task.
- **Model:** A learned or specified mapping from inputs to outputs, often with parameters estimated from data.
- **Overfitting:** When a model fits training data details too closely and performs poorly on new relevant data.
- **Parameter:** A value learned by the model during training, such as a neural-network weight.
- **Precision:** Of the examples predicted positive, the fraction that are truly positive.
- **Recall:** Of the truly positive examples, the fraction found by the model.
- **Regularization:** Methods that constrain learning or model complexity to improve generalization or stability.
- **RAG (retrieval-augmented generation):** A system that retrieves external content and provides it to a generative model as context.
- **Test set:** Data held aside for a final evaluation after model choices are made. Repeatedly tuning to it makes it part of development.
- **Tokenization:** Converting text into units (tokens) a language model can process.
- **Training set:** Data used to fit model parameters and learned preprocessing.
- **Transformer:** A neural-network architecture using attention mechanisms, widely used for text and other modalities.
- **Underfitting:** When a model is too limited or poorly trained to capture useful structure in the data.
- **Validation set:** Data used during development to compare approaches or tune settings; it is not the final untouched test set.
- **Variance:** Sensitivity of a learned result to the particular training sample or random choices.
