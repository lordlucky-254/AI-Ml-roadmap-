# AI / ML Roadmap

A practical, self-paced roadmap for going from zero to working AI/ML practitioner:
**Beginner → Intermediate → Advanced**.

## Stages

| Stage | Focus | Est. time |
|-------|-------|-----------|
| [Beginner](beginner.md) | Python, math foundations, first ML models | 8–12 weeks |
| [Intermediate](intermediate.md) | Classical ML, deep learning, frameworks | 12–16 weeks |
| [Advanced](advanced.md) | LLMs, MLOps, distributed training | 16+ weeks |

Each stage assumes you finish the previous one. Work through the modules in order —
projects are the point, not just reading.

## How to use this roadmap

1. Go module-by-module in order.
2. Do every project. The projects are the curriculum.
3. Use the estimated times as guidance, not a deadline.
4. Build a portfolio repo as you go; a public GitHub history is worth more than certificates.

## Recommended setup

- OS: Linux (or WSL2 on Windows)
- Language: Python 3.12+
- Environment: `uv` or `conda` with isolated environments per project
- Editor: VS Code with the Python, Pylance, and Jupyter extensions
- Hardware: any laptop works for beginner/intermediate; a cloud GPU (Colab, Kaggle, or a rented GPU server) is fine for advanced

## Prerequisites

- Basic computer literacy and the ability to search and read docs
- No prior programming experience required — the Beginner stage starts from zero
